   ├─ تأثير فوري على رصيد الصندوق
   ├─ معاملة محاسبية صحيحة

   └─ إجماليات مع نطاق تاريخي

✅ الميزة 2: تحسين كشوفات الحساب

📌 الوصف:
   كشوفات حساب محسّنة مع ترتيب زمني صحيح وأرصدة تراكمية دقيقة

🔧 الوظائف:

1. كشف حساب العميل:
   ├─ جميع الفواتير والدفعات
   ├─ ترتيب زمني تصاعدي
   ├─ أرصدة تراكمية دقيقة
   ├─ رصيد افتتاحي وختامي
   └─ نطاق تاريخي مرن

2. كشف حساب الصندوق:
   ├─ جميع الحركات النقدية
   ├─ الاستقبالات والمصروفات
   ├─ التحويلات بين الصناديق
   ├─ ترتيب زمني صحيح
   ├─ أرصدة تراكمية دقيقة
   └─ حساب توازن تلقائي

3. الملخصات الشهرية:
   ├─ ملخص شهري لسنة كاملة
   ├─ فصل الأشهر بـ 12 صف
   ├─ لكل شهر: فتح/غلق/معاملات
   └─ يمكن حساب الاتجاهات

4. التصدير:
   ├─ تصدير للـ CSV
   ├─ رؤوس واضحة
   ├─ بيانات منسقة
   └─ جاهز للطباعة والأرشفة

📐 البنية:
   Statement {
     date: ISO date,
     description: string,
     type: 'debit' | 'credit',
     amount: number,
     balance: number (تراكمي)
   }
