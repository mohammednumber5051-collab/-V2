📐 المعادلات المحاسبية الصحيحة

قائمة الدخل (Income Statement):
┌─────────────────────────────────────────┐
│ إيرادات المبيعات            420,000     │
│ - تكلفة البضاعة المباعة    (180,000)   │
├─────────────────────────────────────────┤
│ الربح الإجمالي              240,000     │
│ - المصروفات التشغيلية       (50,000)    │
├─────────────────────────────────────────┤
│ صافي الدخل                 190,000     │
│                                         │
│ هامش الربح = 190,000/420,000 = 45.2%   │
└─────────────────────────────────────────┘

التفاصيل:
├─ Gross Profit = Revenue - COGS
├─ Net Income = Gross Profit - Operating Expenses
├─ Profit Margin = (Net Income / Revenue) × 100
└─ Gross Margin = (Gross Profit / Revenue) × 100

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🎨 ميزات التصميم الاحترافي

1. قائمة الدخل:
   ├─ جدول محاسبي منسق بشكل احترافي
   ├─ ألوان دلالية (أزرق للإيرادات، أخضر للأرباح، أحمر للخسائر)
   ├─ عرض الفئات والمجاميع الفرعية
   ├─ تصميم RTL احترافي للعربية
   └─ بطاقات ملخصة للمؤشرات الرئيسية

2. تحليل الأداء:
   ├─ مقارنة جنباً إلى جنب بين الفترات
   ├─ عرض التغيرات والنسب المئوية
   ├─ أيقونات تشير للاتجاه (↑↓)
   ├─ ألوان تعكس الأداء (أخضر=محسّن، أحمر=منخفض)
   └─ جدول مقارنة شامل مع كل التفاصيل

3. الوضوح للمستخدم العادي:
   ├─ لغة بسيطة واضحة بالعربية
   ├─ رموز ودلالات بصرية قوية
   ├─ أرقام منسقة بشكل قابل للقراءة
   ├─ تصميم تفاعلي مع حركات سلسة
   └─ توازن بين التفاصيل والبساطة
